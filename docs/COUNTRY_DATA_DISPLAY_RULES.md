# Country Data Display Rules

1. Unknown values render as `Unknown`, never `0`.
2. Country population and represented people-group population are distinct metrics.
3. Unreached/frontier labels retain source classifications.
4. Religion shares are derived from people-group records and must not be described as census shares.
5. Coverage is shown beside derived mission metrics where relevant.
6. Scripture categories summarize people-group resource status rather than equal individual access.
7. A country page may render geographic identity without mission statistics when the country data release gate is closed.
8. Source attribution and Natural Earth boundary disclosure remain visible at page level.
