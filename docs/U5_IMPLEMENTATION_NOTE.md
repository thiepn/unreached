# U5 Implementation Note

U5 replaces the Countries placeholder with a searchable geographic index and stable `#/countries/:ISO3` routes. Country detail pages render geographic identity independently from release-gated mission intelligence, and when publishable data is present they expose U4 mission metrics, explicit coverage, ranked unreached peoples, language aggregates, derived religious context, Scripture status, and source identifiers.

Map selections link directly into country profiles when a standard three-letter country code is available; country profiles link back to the selected map area.
