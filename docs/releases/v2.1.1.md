## Unreached v2.1.1 — Release Finalization

Version 2.1.1 closes the 2.1 release line with production-certification, privacy, source-policy, reproducibility and operational hardening. It does not expand the core product scope.

### Release finalization

- Repairs and certifies canonical GitHub Pages production behavior.
- Replaces historical release-number CSS layering with semantic ownership.
- Aligns README, privacy, licensing, source policy and public About copy with actual production behavior.
- Pins Node and dependency resolution and converts release workflows to reproducible `npm ci` installs.
- Adds dependency vulnerability/license auditing and CycloneDX SBOM evidence.
- Adds application CSP/referrer policy and deployed Worker security certification.
- Migrates persistent private-sync account identity storage to hash-only values.
- Documents D1 Time Travel recovery, retention, rollback and incident response.
- Adds scheduled Pages/PeopleGroups/Worker operational health checks.
- Adds final content/theology/source certification and maintenance-mode governance.

### Content and prayer review

- All 12 Tier-3 editorial profiles were reread for identity, source support, temporal framing, religion nuance, stereotyping risk and sensitive-data exposure.
- Higher-risk current claims were rechecked against their cited institutional source layer.
- PeopleGroups.org identity/GSEC/resource fields remain live-runtime data and are not redistributed as a static corpus.
- The fixed `u12c-v1` prayer template was re-reviewed on 29 August 2026 for biblical grounding, non-coercive tone, factual boundaries and sensitive-information safety.

### PWA and accessibility

- Adds PNG PWA icons at 192 and 512 pixels plus an Apple touch icon while retaining the SVG source icon.
- Adds final PWA asset/manifest and offline-shell acceptance coverage.
- Adds portrait/landscape and narrow-layout acceptance on the full browser/device-class matrix.
- Existing reduced-motion, contrast, target-size, keyboard/focus and horizontal-overflow certification remains blocking.

### Privacy and private continuity

- Local-only use remains the default.
- Private sync remains explicit and opt-in.
- The server continues to exclude browsing history, prayer history, counts, streaks, rankings, scores and the PeopleGroups corpus.
- The legacy D1 `email` compatibility column is scrubbed/enforced to the same SHA-256 identity value as `user_id`; plaintext email is not intentionally persisted.

### Certification

Release publication is exact-SHA gated and requires:

- deterministic build and Phase 1–5 policy gates;
- dependency vulnerability/license audit;
- full Chromium, Firefox, WebKit, mobile Chromium and mobile WebKit certification;
- PeopleGroups live corpus/CORS/editorial certification;
- GitHub Pages deployment and canonical production browser certification;
- deployed private Worker health/security/CORS/Access certification;
- successful production commit statuses for Pages, PeopleGroups and Worker production.

### Acceptance boundary

Automated mobile acceptance uses Pixel 7 Chromium and iPhone 15 WebKit device emulation with touch. This execution environment has no connected physical iOS/Android hardware or external real-device testing provider, so the release does **not** misrepresent physical-hardware testing as completed.

GitHub's current repository administration reports `main` without branch protection. CODEOWNERS, exact-SHA release gating and maintenance governance are included, but branch-protection/ruleset enablement is not falsely claimed by this release.
