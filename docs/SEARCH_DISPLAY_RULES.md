# Search & Saved Display Rules

1. Search only indexes data that is already available to the browser.
2. Search must never imply that an unavailable source dataset was searched.
3. Country search may use the local Natural Earth geographic inventory independently of mission-data availability.
4. Search result labels use canonical published names from their domain datasets; aliases are searchable but are not silently substituted as canonical display names.
5. Search results remain grouped as Peoples, Countries and Languages even when one group has no published data.
6. Saved people snapshots are convenience metadata, not source truth. Live profile content overrides stale saved labels or classifications.
7. `Save for Prayer` means local bookmarking only. It does not record that a user prayed.
8. Recent exploration records navigation only. It does not record prayer completion or infer spiritual activity.
9. Saved/recent state must not be displayed as public social proof, counts, streaks or achievements.
10. If browser storage is unavailable, the app remains usable and must not claim persistence succeeded beyond the current UI state.
